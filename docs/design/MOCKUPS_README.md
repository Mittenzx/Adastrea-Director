### Unreal Engine Plugin Mockups

#### 1. Main Query Interface
- Single-line query input
- Scrollable results with formatted responses

- Real-time AI responses

#### 2. Document Ingestion Interface
- Path selection with browse dialogs
- Real-time progress bar (0-100%)

- Status icons (✓ done, ⏳ processing, ⏹ pending)

#### 3. Settings Panel
- API provider selection (Gemini/OpenAI)

- Display preferences

- Demonstrates seamless workflow integration

- Conversation history

## ❓ FAQ

**Q: Why ASCII mockups instead of images?**
A: ASCII mockups are version-control friendly, easy to edit, and work in any environment.

**Q: Can I modify these for my project?**
A: Yes! These mockups are part of the open-source project.

**Q: Where's the actual implementation?**
A: See `Plugins/AdastreaDirector/Source/AdastreaDirectorEditor/` for UE plugin and `gui_director.py` for standalone GUI.

**Q: Are these final designs?**
A: These represent the current design direction. They may evolve based on feedback and implementation needs.

**Q: How do I provide feedback?**
A: Open an issue on GitHub with the "design" label.
